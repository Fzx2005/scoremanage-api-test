# 学生成绩管理系统 接口自动化测试框架
## 技术栈
Python3 + Pytest + Requests + Allure 可视化测试报告

## 一、项目目录结构说明
1. common/http_client.py
封装通用HTTP请求方法，统一处理Session会话、请求头、接口异常捕获，减少用例重复代码。

2. testcases 测试用例模块
- test_student_module.py：学生端个人查询、成绩查看等权限接口测试
- test_teacher_module.py：管理员/教师端学生、成绩增删改查正向&边界用例
- test_unauth_access.py：安全反向用例，覆盖未登录绕过、角色越权访问、非法参数提交校验

3. config.py
全局环境配置文件，统一管理测试服务地址、端口、管理员/学生测试账号密码，方便切换环境。

4. conftest.py
Pytest全局夹具文件，实现session级别登录前置，全局复用登录会话，用例执行完成后置退出登录。

5. pytest.ini
Pytest运行规则配置，设置用例编码、测试用例搜索规则、日志级别。

6. reports
Allure测试报告自动生成目录，执行脚本后会在此生成报告原始数据。

7. run_all.py
项目一键执行入口，自动调用pytest执行全部用例并生成Allure可视化报告。

## 二、本地部署&运行步骤
### 1. 安装依赖
# 1. 创建虚拟环境（可选）
python -m venv .venv
# 2. 激活虚拟环境后执行依赖安装
pip install -r requirements.txt

### 2. 一键执行自动化用例
python run_all.py

### 3. 打开可视化测试报告
allure open reports/allure-results

## 三、自动化覆盖核心测试点
1. 功能正向流程：登录、学生CRUD、成绩新增/修改/删除、分页查询
2. 边界参数测试：超100分成绩、负数页码、非法ID等校验场景
3. 安全测试：未登录直接调用后台接口、学生越权修改他人数据等高危漏洞验证
4. 回归验证手工测试发现的19条系统缺陷

## 四、项目重要说明

1. 被测原始 jar 包合计 19 条待修复缺陷：BUG‑001~018 来自手工测试，**BUG‑019 会话阻塞缺陷为接口自动化脚本发现**。
2. 使用交付包内原始 jar 运行：登录请求成功，但受 BUG‑019 影响，后续业务接口全部返回 401。
3. 本地 IDE 环境已修复 BUG‑001~018 业务缺陷，但未修复 BUG‑019，该 IDE 工程不对外交付。
4. 脚本完整保留正向、反向、越权全部测试用例，不会为了用例全部通过删减测试 case。
